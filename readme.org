* Atlas

Reverted to the working prototype for simplicity, to get over the
production line now. Later hotswap/ADC work lives in
=archive/v2-hotswap-ads1220/=.

34-key split ergonomic keyboard with a trackpoint on each half and an
optional oversized trackball. XIAO nRF52840, BLE split, ZMK in
=zmk-workspace-ble/=. Board in =pcb/atlas/=, case and plates in =stl/=.

** Architecture

#+begin_example
Host <--BLE-- Left (central + trackpoint) <--BLE-- Right (peripheral + trackpoint)
#+end_example
