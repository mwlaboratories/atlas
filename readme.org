* Atlas

34-key split ergonomic keyboard with trackpoint. Per-half XIAO nRF52840,
BLE split, ZMK firmware, Choc V2 hotswap, 20 × 17 mm column stagger.

** Status (October 2026)

- Daily driver: breakout-board prototype, Sprintek AIO trackpoint on the
  left half. Pinned at the =proto/breakout-v1= tag.
- PCB: hotswap board ordered (5 panels, fully assembled). Each panel holds
  both halves.
- ADS1220 strain-gauge trackpoint: firmware bench-proven (HID mouse,
  radial deadzone, click-to-wake) at the =bench/ads1220= tag; on the PCB
  per half.

** Trackpoint wiring

Sprintek SK8707 bare strain-gauge stick, read by an ADS1220 per half.
Stick up, ribbon to the left, contacts far → near:

| b | REFN0 | supply − |
| a | REFP0 | supply + (excitation current) |
| y | AIN1  | left/right output |
| x | AIN0  | away/toward output |

The right half's stick is turned 180°, so its J1 order is reversed.
Verified with a multimeter on the real stick (October 2026).

** Mouse layer

When the trackpoint moves, the mouse layer auto-activates for ~1 s after
the last movement.
