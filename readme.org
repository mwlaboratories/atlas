* Atlas
34-key split keyboard with dual TrackPoints, using XIAO BLE controllers.

** Status (Feb 2026)
- Left side TrackPoint working (Sprintek all-in-one module)
- Right side TrackPoint configured (same setup as left)
- Mouse layer auto-activates on trackpoint movement
- Scroll mode working
- BLE split (no dongle)

** Architecture
#+begin_example
Host <-- Left (central + trackpoint) <-- Right (peripheral + trackpoint)
#+end_example

** Mouse Layer
When moving trackpoint, the mouse layer auto-activates for 1 second after last movement.

#+begin_example
Thumb keys:
| SCROLL | LCLK | LCLK | RCLK |
#+end_example

- *Scroll*: Hold to convert movement to scroll wheel

** Hardware Notes
- TrackPoint: Sprintek all-in-one module, PS/2 via UART
- Pins: D6 (SCL), D7 (SDA), P0.09 (reset)
- Both sides use identical wiring

** Build
#+begin_src bash
nix develop
just all      # build both sides
just left     # build left only
just right    # build right only
just keymap   # generate keymap SVG
#+end_src

Firmware outputs to =zmk-workspace-ble/firmware/=.
