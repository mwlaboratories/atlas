#+TITLE: Atlas PCB Generation Pipeline

* Overview

Everything for PCB generation lives in this directory.
Edit =keyboard.yaml= here, run the pipeline from the repo root with =just=.

* Directory

#+begin_example
tools/
├── keyboard.yaml                ← INPUT: you edit this
├── layout2kle.py                ← YAML → KLE JSON
├── pcb_build.py                 ← unified PCB generator (kbplacer + enhancements)
├── step_build.py                ← STEP assembly (bare PCB + trackpoint modules)
├── kicad/                       ← KiCad input files
│   ├── 3dmodels/                ← 3D models (switches, diodes, assembled trackpoint)
│   │   └── *.step / *.wrl
│   └── footprints/              ← custom footprints (connectors, controller)
│       └── *.kicad_mod
├── build/                       ← all generated output (gitignored)
│   ├── layout.json              ← KLE intermediate
│   ├── atlas.kicad_pcb          ← generated PCB
│   ├── atlas.step               ← PCB + trackpoint modules (after pcb-step)
│   ├── 3dmodels → ../kicad/3dmodels   (symlink for KiCad)
│   └── footprints → ../kicad/footprints
└── readme.org
#+end_example

* Pipeline

#+begin_example
  keyboard.yaml
       │
       │  just pcb
       │
       ├─ 1. layout2kle.py → build/layout.json (KLE JSON)
       │
       └─ 2. pcb_build.py  → build/atlas.kicad_pcb
             • kbplacer: switch + diode placement
             • 3D models, trackpoint holes, controller, edge cuts
             • symlinks kicad/3dmodels + kicad/footprints into build/

  just pcb-step  (after pcb)
       │
       ├─ 1. kicad-cli → build/pcb_bare.step
       ├─ 2. step_build.py places assembled_trackpoint.step modules
       └─ 3. → build/atlas.step + opens f3d viewer
#+end_example

* Build PCB

#+begin_src bash
nix develop          # enter dev shell
just pcb             # YAML → build/atlas.kicad_pcb
just pcb-step        # STEP assembly: bare PCB + trackpoint modules
#+end_src

Dependencies (kbplacer, kiswitch footprint library) are managed by Nix.
No manual setup step required.
