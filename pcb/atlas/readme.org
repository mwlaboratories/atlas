#+title: Atlas PCB

KiCad project for the Atlas keyboard PCB. Workflow:

1. =tools/layout/index.html= → pick layout → copy KLE JSON
2. Paste into [[https://editor.keyboard-tools.xyz][editor.keyboard-tools.xyz]] → download KiCad project
3. Drop the unpacked project into this directory
4. Open the =.kicad_pro= in KiCad and finish: controller footprint, edge cuts, routing, etc.

The =layout.json= snapshot can be saved here so the design is reproducible.
