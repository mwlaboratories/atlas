#+title: Atlas PCB

Source files for the Atlas keyboard PCB — a hand-laid KiCad board.

* Files

| =kicad/=              | KiCad project — =keyboard.kicad_pcb= is the source of truth. |
| =parts.yaml=          | BOM — LCSC part numbers, disposition.                        |
| =parts-checklist.org= | Pre-fab checklist for JLCPCB ordering.                       |
| =keyboard.json=       | Original layout reference (KLE-style).                       |

* Workflow

The board is laid out by hand in KiCad — there is no generator.
=kicad/keyboard.kicad_pcb= is the artifact, edited directly.

1. Place / adjust footprints and route in KiCad.
2. Tag each footprint with its =LCSC= field from =parts.yaml=.
3. Run *Fabrication Toolkit* → upload the zip to JLCPCB.
