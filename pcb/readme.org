#+title: Atlas PCB

Source files for the Atlas keyboard PCB.

* Layout

| =keyboard.json=         | Layout source (KLE-style). Drives PCB design tooling. |
| =keyboard.svg=          | Rendered layout preview.                              |
| =keyboard-outline.svg=  | PCB edge cuts.                                        |
| =keyboard-plate.svg=    | Switch plate outline (matches =/keyboard-plate.stl=). |
| =parts.yaml=            | BOM — LCSC part numbers, disposition.                 |
| =parts-checklist.org=   | Pre-fab checklist for JLCPCB ordering.                |
| =kicad/=                | KiCad project — all generated files contained here.   |

* Workflow (ergogen-driven)

1. Start the dev server: =dev= (alias for =node tools/server.mjs=)
2. Open =http://localhost:8000= — the atlas layout webtool.
3. Adjust columns / thumbs / trackpoint to taste.
4. Click *⚙ build PCB* → server:
   - converts layout state → ergogen YAML (=../tools/layout-to-ergogen.mjs=)
   - runs ergogen → =kicad/keyboard.kicad_pcb=
   - renders top + bottom views to =../tools/renders/= and shows in webtool
5. Iterate. When happy, the .kicad_pcb is ready for routing in KiCad.
6. In KiCad: route, tag LCSC fields from =parts.yaml=, run *Fabrication
   Toolkit* → upload zip to JLCPCB.

* Source-of-truth files

- =keyboard.json=          — atlas layout (auto-saved by webtool to localStorage; export via webtool)
- =kicad/keyboard.kicad_pcb= — generated by the build pipeline
- =parts.yaml=             — BOM; tag symbols with these LCSC codes before fab
- =parts-checklist.org=    — JLCPCB ordering checklist
