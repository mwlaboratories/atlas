#+title: Atlas Parts Library

Project-local registry tying KiCad footprints to JLCPCB LCSC part numbers,
so PCBA orders can be assembled without manual BOM massaging.

* Layout

#+begin_src
pcb/lib/
├── parts.yaml             ← canonical part registry (LCSC, footprint, disposition)
├── footprints/            ← custom .pretty libs for parts not in stock KiCad libs
│   └── Seeed_XIAO.pretty/   (mirror of pcb/atlas/footprints/Seeed_XIAO.pretty/)
├── symbols/               ← future: schematic symbols (.kicad_sym) if we go full schematic
└── 3dmodels/              ← 3D STEP files for custom footprints
#+end_src

* Workflow

1. kbplacer generates the PCB with switches placed.
2. =pcb/atlas/add_leds.py= drops LED footprints.
3. =pcb/atlas/merge_outline.py= adds the plate edge cuts.
4. (TODO) =pcb/atlas/tag_lcsc.py= reads =parts.yaml= and writes the LCSC
   property into every footprint in the PCB.
5. KiCad =File → Fabrication Outputs → BOM= picks up the LCSC field;
   =File → Fabrication Outputs → Component Placement= emits the CPL file.
6. Upload Gerber zip + BOM + CPL to JLCPCB PCBA.

* Disposition guide

| disposition       | who solders             | example part         |
|-------------------+-------------------------+----------------------|
| =pcba=            | JLCPCB                  | LEDs, hotswap, diodes |
| =pcba_only_consign= | JLCPCB if you mail stock | (none currently)     |
| =dnp=             | you, by hand            | XIAO, SK8707         |
| =plug_and_play=   | nobody (slots in)       | Choc V2 switch       |
