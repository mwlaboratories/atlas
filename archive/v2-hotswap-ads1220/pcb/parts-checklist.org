#+title: Atlas Parts Checklist — JLCPCB / LCSC lookup
#+startup: indent

Each part: what to search for, quantity per half, expected stock category,
and the LCSC code field to fill in once verified. The Atlas design uses
*BLE between halves*, so each half is independent → everything below
times two for a full keyboard.

When you verify a code, edit the =LCSC:= line and tick the checkbox.
The =parts.yaml= file alongside this one is the canonical machine-readable
source; this file is the human-friendly view to use while shopping.

* Status legend

- =Basic= — JLCPCB always-stocked, no setup fee
- =Extended= — Stocked but ~$3 setup fee per unique part
- =Pre-order= — JLCPCB orders for you, may have minimum quantity
- =Consign= — You ship them stock; not usable for standard PCBA
- =DNP= — Do Not Place; hand-solder after delivery

** No boost converter (decided from ZMK community guidance)
- SK6812MINI-E only needs 3.4V for logical-high — LiPo (3.0-4.2V) is enough.
- Reference: [[https://github.com/ebastler/zmk-designguide][ebastler/zmk-designguide]] (the de-facto wireless-ergo design guide).
- Trade-off: LEDs may dim near empty battery, but no extra IC needed.

** [ ] LED power-cutting MOSFETs (CRITICAL for battery life)
- Why: SK6812 quiescent draw ~1 mA per LED *even when "off"*.
  17 LEDs × 1 mA = 17 mA constant drain — 100× the BLE radio current.
- Solution: P-channel MOSFET on the LED VDD rail, gated by XIAO GPIO (=UG_EN=).
  Common topology in ebastler's guide: P-FET + N-FET pair for clean switching.
- Search: "P-channel MOSFET SOT-23" + "N-channel MOSFET SOT-23"
  - Common picks: AO3401 (P-FET), AO3400 (N-FET)
- LCSC P-FET: TBD (AO3401 is ~=C15127=) ← verify
- LCSC N-FET: TBD (AO3400 is ~=C20917=) ← verify
- Stock: Basic
- Footprint: =Package_TO_SOT_SMD:SOT-23=
- Qty per half: 2 (one P, one N)  ·  Total: 4
- Plus gate pull-up/down resistors (10 kΩ, ~2 per side)

** [ ] LED data-line level shifter MOSFET
- Why: XIAO's 3.3V data signal can be unreliable for SK6812MINI-E
  at battery voltage. Single N-FET inverts-and-shifts to VBAT level.
- Topology: N-FET with pull-up to VBAT — ZMK has a config flag for this.
- Search: same N-channel MOSFET as above (often AO3400)
- LCSC: shared with the power-cut N-FET
- Qty per half: 1  ·  Total: 2
- Plus pull-up resistor (1-2.2 kΩ)
